# 宝妈勇闯自媒体 · 移动端创作工作台

手机 App 风格的单文件创作工作台（无后端、无数据库，数据存浏览器 localStorage）。

## 手机访问地址（GitHub Pages）
https://yadiannana.github.io/mama-studio/

## 每日自动更新
- GitHub Actions 定时任务：北京时间 早8点 / 下午2点 / 晚8点 自动运行
- 抓取抖音/微博/知乎/头条/60s 全网热榜 + 指定微信专辑文章（可选）
- 用 DeepSeek 改写成贴合「宝妈勇闯自媒体」赛道的内容：10 条选题灵感 + 10 条爆款二创角度 + 10 条图片文案（钩子严格 12-15 字）+ 20 道速算 + 5 个英语单词
- 结果推送至公开 Gist，网页默认读取该 Gist，带刷新按钮

## 七个模块
1. 每日计划（进度条 + 可勾选清单）
2. 选题每日灵感（关联宝妈自媒体，一键唤起抖音/B站/小红书）
3. 爆款二创（热点 + 改编角度 + 学习爆火文案 + 深度模仿）
4. 内容复盘（播放/点赞/评论/转发 + 亮点/问题/优化）
5. 备忘录（默认 5 行，可勾选可加行）
6. 速算练习（自动导入，本地兜底）
7. 英语练习（零基础计划 + 单词 + 语法 + 影子跟读，逐字跟读 + 录音）

## 仓库结构
- index.html  单文件网页（部署到 Pages）
- gen.py      每日内容生成器（抓取热榜 + AI 改写 + 推送 Gist）
- sources.json 金句库/通透句库/人名日报（可替换为你的真库）
- .github/workflows/daily.yml  定时任务
